# z.a.t.o // i love the backgrounds and all the filters on them

i've always really loved the backgrounds in zato, so i made a tool that lets anyone make one!

a smol little weekend project made for [hack club wrangler!](https://wrangler.hackclub.com)

no generative ai used except for debugging the filter effects

## features:

- hue
- saturation
- lightness
- contrast
- posterize level
- color noise amount
- cropping
